3. 能力对比

当前架构

  • ✗ 工具调用能力
  • ✗ 多步任务自动分解
  • ✗ 持久化 Memory
  • ✓ 意图识别路由
  • ✓ 会话管理（内存）
  • ✓ 三层置信度评估

改造后架构

  • ✓ Tools 工具系统 - 文件读写/代码执行
  • ✓ ReAct 循环 - 自动多步推理
  • ✓ Checkpointer - PostgreSQL/SQLite 持久化
  • ✓ 保留意图识别路由
  • ✓ 保留会话管理
  • ✓ 保留三层置信度评估

4. CodeAgent 工具设计

@tool: read_file
读取文件内容，支持指定行范围
@tool: write_file
写入/创建文件，支持追加和覆盖模式
@tool: execute_code
执行 Python 代码，返回 stdout/stderr
@tool: explain_code
解释代码功能和逻辑

5. LangChain 特性集成评估

LangChain 特性 当前支持 集成难度 优先级
create_agent 未使用 中 高
@tool 装饰器 未使用 低 高
MemorySaver 自实现 中 中
PostgresSaver 计划 MySQL 高 低
LangGraph 未使用 高 低

6. 改造关键点

核心变更：将 CodeAgent.run() 从直接调用 LLM 改为使用 create_agent + Tools

旧方式
llm.ainvoke(messages)
→
新方式
agent.invoke({"messages": [...]})
